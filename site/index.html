dictate

Speak into any text field on GNOME.

Install Configure Source Releases

What it does

  • Local. Speech is transcribed on your machine by whisper.cpp. Audio never leaves it unless you point dictate at a server of your own, and each recording is deleted once it is text.
  • Text while you speak. The recording is transcribed at each pause and shown as you go; when you stop, the whole of it is transcribed once more, so the typed text reads as one stream.
  • Shown before it is typed. Each piece appears in the field, underlined, as you speak. Typing a key or moving focus takes it off; the final text is what gets typed.
  • Into the right field. An IBus input method inserts the text into the input that had focus when you started. If focus moved, the text goes to the clipboard instead.
  • Nothing lost. An optional log keeps every dictated text on your machine, readable by you alone.
  • One shortcut per language. Super+I for English and Super+E for Spanish by default; add any language whisper knows.
  • Four ways in. The input method by default, or a paste, typed keys, or the clipboard alone.
  • Status everywhere. A tray icon that blinks while recording, a tmux segment, and notifications when something goes wrong.
  • Never in a password field. Nothing is shown in, typed into or logged from a password or PIN field.

Ubuntu 24.04 or later, GNOME on Wayland.

Install

Ubuntu 26.04 or later, with a local transcriber:

sudo curl -fsSLo /etc/apt/sources.list.d/dictate.sources https://jvrsantacruz.github.io/dictate/dictate.sources && sudo apt update && sudo apt install dictate dictate-indicator dictate-whisper && dictate setup

Ubuntu 24.04, or a transcriber of your own (configure it):

sudo curl -fsSLo /etc/apt/sources.list.d/dictate.sources https://jvrsantacruz.github.io/dictate/dictate.sources && sudo apt update && sudo apt install dictate dictate-indicator && dictate setup

Configure

dictate setup sets up a user: the input method, the shortcuts, the tray icon and ~/.config/dictate/config. Run it again with any option below to change that setting; --dry-run shows the changes without making them.

Settings are read from three places, each over the one before: /etc/dictate/config for every user of the machine, ~/.config/dictate/config for yours, and DICTATE_* variables in the environment for one run, such as DICTATE_METHOD=type dictate en. Both files are KEY="value" lines.

dictate log prints the last 20 dictated texts, and dictate cancel stops a recording without transcribing it. Everything else: the README.
